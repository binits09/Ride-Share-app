# User & Driver Guide

## User: Booking a Ride
1. Open the Ride page
2. Enter pickup and dropoff — suggestions appear as you type
3. Click Search to preview the route and options (bike/car)
4. Choose an option → request is sent
5. Track status: searching → requested → accepted → arrived → ongoing → completed → paid

Rules:
- Cannot select identical pickup and dropoff; UI shows an alert
- Payment method defaults to cash unless configured otherwise

## Driver: Workflow
1. Go Online (status) to receive rides
2. Claim/searching rides or accept assigned rides
3. Arrive at pickup → Start ride → Complete → Mark Paid
4. View earnings and summary in the driver account pages

## Notifications & UX
- Professional Toasts replace browser alerts
- Booking inputs have icons and glow styling for clarity
- Driver Home includes quick stats and features (if enabled)

## Tips
- Ensure location inputs are specific for better suggestions
- Keep the app updated; dependent services (ORS, MongoDB) must be reachable
